Nothing runs without a receipt.

DEDSEC separates target availability from security conclusions. Every module is process-isolated behind a hard deadline, every HTTP request is scope-checked and budget-bounded.

  1. 01Preflightbounded TCP reachability, no dead waits
  2. 02Isolateeach module in its own killable process
  3. 03Probescoped, verified TLS, bounded retries
  4. 04Observesignature-validated, soft-404 aware
  5. 05Correlateobservation → candidate → verified finding
  6. 06Reportschema 2.1, evidence IDs, redaction

The arsenal.

Twenty-six scoped modules, grouped by what they answer. Each runs bounded and reports its uncertain outcome honestly as inconclusive.

// discovery

  • subdomainsmulti-source enumeration, unresolved-candidate preservation
  • contenthigh-value path probing with soft-404 filtering
  • dirlistingsignature-validated autoindex detection
  • jsin-scope JS assets, typed routes, API candidates, secret-shape detection
  • api_schemapublic OpenAPI/Swagger discovery and endpoint mapping
  • vhostin-scope Host-header response-difference candidates

// posture

  • headersweighted header-coverage and disclosure posture
  • cspCSP directive hardening observations
  • cookiescookie security attributes and scope
  • corscross-origin configuration candidates, no impact overclaiming
  • clickjackingframing restrictions and frameability observations
  • exposuressignature-validated sensitive exposure checks

// endpoint & network

  • portsbounded TCP service discovery, explicit network-state classification
  • sslverified certificate and protocol analysis
  • dnsrecords, auth posture, DNSSEC, labeled AXFR check
  • emailDNS-only SPF, DMARC, DKIM-selector, MX posture
  • http_methodsmethod declarations and bounded TRACE validation
  • redirectcontrolled open-redirect analysis, no external-follow

One command, a full scope-honest run.

Drop it into any authorized scope. `--timeout` is the whole logical request deadline; `--module-timeout` and `--global-timeout` bound the outer scan. Nothing hangs.

full scan
dedsec https://example.com
scoped + bounded
dedsec https://example.com -m tech,dns,ssl,headers \
  --concurrency 4 --module-timeout 120 \
  --global-timeout 600 --max-requests 1000

Get started in 60 seconds.

Runs on Python 3.8–3.13. Install into a venv and point it at a target you own or are authorized to test.

install
git clone https://github.com/Aether-DZ/dedsec
cd dedsec
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
